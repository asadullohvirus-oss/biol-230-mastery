# BIOL 230 Mastery

Canonical long-term state for an accelerated Athabasca University BIOL 230: Human Physiology learning system.

## Primary objective

Complete BIOL 230 by approximately December 1–5, 2026 while targeting an A/A+ and genuine mechanism-based mastery, with enough administrative buffer for the final grade, Home Lab Kit return, and transcript availability before the January 17, 2027 Dalhousie MPAS Section 2 deadline.

## Architecture

- Athabasca BIOL 230 materials = academic source of truth
- ChatGPT Project = active learning, retrieval, reasoning, assessment, planning
- GitHub = canonical durable state and history
- Anki = spaced-repetition scheduling for selected high-value cards
- Google Calendar = hard milestones and risk-control reminders only

## Canonical files

- PROJECT-INSTRUCTIONS.md — authoritative behavior for the ChatGPT Project
- COURSE-MAP.md — official course/assessment map and known scope
- ROADMAP.md — accelerated October 1 to early-December plan
- PROGRESS.md — live completion/mastery dashboard
- GRADEBOOK.md — marks and grade projection
- OPERATIONS.md — lab kit, exams, transcript, and admissions-critical logistics
- MASTERY.md — objective-level demonstrated mastery
- MISTAKES.md — meaningful recurring conceptual errors
- units/ — unit-level learning state
- assessments/ — benchmark snapshots
- anki/pending.tsv — cards awaiting Anki import

## Repository rules

This repository stores state, not course content.

Do not commit:
- copyrighted textbook PDFs or copied textbook chapters,
- assignment questions,
- quiz/exam questions,
- full ChatGPT transcripts,
- large generated summaries.

Historical assessment snapshots should remain unchanged once finalized. Update durable state only when something meaningful changes.
